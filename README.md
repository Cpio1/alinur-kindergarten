# Алинур — сайт детского сада

Next.js (App Router), TypeScript, Tailwind CSS, Motion. Два языка: казахский (основной) и русский.

```bash
npm install
npm run dev        # http://localhost:3000
npm run typecheck
npm run build
```

## Структура

| Папка | Назначение |
| --- | --- |
| `app/` | layout, страница, SEO, sitemap, robots |
| `website/` | интерфейс для компьютера (от 1100 px) |
| `mobile-website/` | отдельный интерфейс для телефонов и планшетов (до 1099 px) |
| `shared/content/site.ts` | контакты, ссылки, координаты |
| `shared/i18n/translations.ts` | все тексты на двух языках |
| `shared/lib/media.ts` | поиск фото и видео в `public/images` |
| `shared/ui/` | общие компоненты: просмотр фото, карта 2ГИС (только компьютер), декор |

Сервер отдаёт оба интерфейса, CSS показывает нужный, а после загрузки лишний удаляется из DOM (`shared/ui/ViewportSwitch.tsx`).

## Как добавить фотографии

Положите файлы в `public/images/` и пересоберите сайт. Код менять не нужно. Форматы: PNG, JPG, JPEG, WebP.

| Файл | Где показывается |
| --- | --- |
| `main-page.*` | первый экран (пока файла нет, показывается иллюстрация) |
| `main-page2.mp4` или `main-page2.*` | большой блок в разделе «Біз туралы» (видео важнее фото; без файлов блока нет) |
| `image1.*`, `image2.*`, `image3.*` … | галерея по порядку номеров; `image1` также показывается в «Біз туралы» |

Удобнее добавлять снимки в галерею скриптом:

```bash
npm run photos:add -- ~/Desktop/alinur-photos
npm run build
```

Скрипт присваивает следующие номера `imageN`, ничего не удаляет и не перезаписывает, пропускает дубликаты, сохраняет пропорции, уменьшает снимки до 1920 px, сохраняет их в WebP и убирает метаданные, включая геолокацию. Файлы `main-page` и `main-page2` он не трогает.

Используйте только фото, на которые у сада есть права, и только с согласия родителей, если на снимках видны дети.

## Настройки

Скопируйте `.env.example` в `.env.local`. На Vercel те же значения задаются в Project Settings → Environment Variables, после чего нужен новый деплой.

- `NEXT_PUBLIC_SITE_URL` — адрес сайта, например `https://alinur.edu.kz`. Используется в SEO, sitemap и Open Graph.
- `NEXT_PUBLIC_DOCUMENTS_URL` — https-ссылка на папку Google Drive. После её добавления в разделе «Құжаттар» появится кнопка, открывающая папку в новой вкладке.

## Публикация на Vercel

1. Загрузите репозиторий на GitHub и импортируйте его в Vercel. Настройки сборки определятся автоматически.
2. Подключите домен в Project Settings → Domains и обновите `NEXT_PUBLIC_SITE_URL`.
